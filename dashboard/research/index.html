Data & methodology

What these counts can and cannot tell you.

Dataset

Counting method

Results count distinct linked profiles. Unlinked records count separately. A profile may appear in more than one condition or source, so breakdown totals may exceed the cohort count. Associations do not establish treatment effects.

Clinical coverage

The current dictionary recognizes six condition families using English terms and selected ICD codes. Other records are Unclassified. Demographics require recognized structured fields; unknown values stay visible.

Release boundaries

The console reads only files listed as sanitized in the release manifest. It does not serve source files, identifiers, free text, or the release directory. Strict-blocked releases are rejected.

Small-group suppression

Breakdowns containing a group below the API's minimum are withheld in full. Repeated queries may still permit inference. A public real-data deployment needs reviewed disclosure controls.

Reproducible exports

CSV exports include the dataset mode, applied filters, counting method and released breakdowns. Saved cohorts store filter definitions locally.
